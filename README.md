# CUMALATOR

Kalkulator IPK untuk membantu mahasiswa memantau hasil akademik dengan mudah.

## Masalah
Mahasiswa sulit menghitung IPK secara cepat dan akurat tanpa mencatat manual.

## Cara menjalankan
1. Unduh atau clone repositori ini.
2. Buka `index.html` di Chrome atau Firefox.
3. Tidak perlu instalasi tambahan.

## Dokumentasi
- [Project Charter](docs/CHARTER.md)
- [Roadmap](docs/ROADMAP.md)

## Struktur folder
- `index.html` — halaman utama
- `src/` — kode JavaScript dan CSS
- `assets/` — gambar dan aset
- `docs/` — charter, roadmap, dan dokumentasi lain
